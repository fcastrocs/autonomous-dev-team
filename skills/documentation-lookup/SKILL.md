# Documentation Lookup

Use this skill only when the answer depends on external behavior that may have changed or cannot be established from pinned versions and local source.

1. Identify the exact product, version, symbol, and unresolved question from repository files first.
2. Prefer local documentation and pinned dependency metadata, then official vendor documentation or primary specifications.
3. Keep searches narrow and stop once the required behavior is supported by direct evidence.
4. Record the version or date when relevant and distinguish sourced facts from inference.
5. Return links or precise source locations with the conclusion.

Never paste credentials or proprietary code into external searches. Do not use community summaries when an authoritative source answers the question.
